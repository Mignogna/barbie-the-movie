## Ingressos de Cinema

Este é um projeto de **Javascript** criado por mim simulando a venda de ingresso do cinema para assistir o filme da Barbie.
O usuário tem acesso ao trailer do fime, sinopse, apresentação dos personagens através de um slide, pode
escolher o endereço do cinema, a data, a sessão, escolher o assento e depois simular o pagamento. Ao final, o eticket é printado na tela com todos os dados inclusos.


## Cinema Tickets

I built this **JavaScript** project to simulate buying movie tickets for the Barbie film. It lets users watch the trailer, read the synopsis,
see a character presentation via a slideshow, and then choose the cinema address, date, showtime, and seats. After simulating payment, a complete e-ticket is printed on the screen.
